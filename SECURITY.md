# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| latest  | ✅        |

## Reporting a Vulnerability

If you discover a security vulnerability in this website's code, please report it responsibly:

1. **Do not open a public GitHub issue** for security vulnerabilities.
2. Email security@kibologic.com with details of the vulnerability.
3. Include steps to reproduce, impact assessment, and suggested fix if known.
4. We will respond within 48 hours and aim to resolve critical issues within 7 days.

## Scope

This policy applies to the alpine-website source code repository. For Alpine ERP product security issues, contact security@kibologic.com directly.
